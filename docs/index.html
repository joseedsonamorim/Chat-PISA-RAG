Como funciona por trás

  • Base fechada: o sistema não pesquisa na web. Ele lê somente os PDFs do PISA indexados na pasta data/.
  • Busca híbrida: combina busca semântica por embeddings (gemini-embedding-001) com busca por palavras-chave (BM25), unindo os resultados por Reciprocal Rank Fusion.
  • Verificação imediata: toda resposta indica o código do trecho usado (ex.: C120). Ao clicar nele, a página exata do manual é destacada na coluna da esquerda.
